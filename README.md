Advanced Todo App

A feature-rich Task Management Web Application built using HTML, CSS, and JavaScript.

This Todo App supports task creation, editing, filtering, subtask tracking, progress management, drag-and-drop reordering, and due date handling — all inside a clean, responsive UI.
